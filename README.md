# PulseMeter

> 一個簡潔、即時的網速檢測器。

[立即測速](https://pulsemeter-speed-test-20261010.leafygrape16.chatgpt.site)

PulseMeter 讓你用一個按鈕快速了解目前裝置的網路狀況。它會依序量測連線回應、下載與上傳速度，並以清楚的數字呈現結果。

## 可以看到什麼？

- **下載速度**：從網路接收資料的速度，會影響影片播放、檔案下載與網頁載入。
- **上傳速度**：將資料送往網路的速度，會影響視訊通話、雲端備份與檔案分享。
- **Ping**：裝置與測試端點往返一次所需的時間；數值越低，通常代表回應越快。
- **Jitter**：Ping 的波動程度；數值較低通常代表連線較穩定。

## 如何使用

1. 開啟 [PulseMeter](https://pulsemeter-speed-test-20261010.leafygrape16.chatgpt.site)。
2. 按下「開始測速」。
3. 等待測試完成，即可查看下載、上傳、Ping 與 jitter。

## 隱私

PulseMeter 不需要帳號，也不會保存你的測速結果。測試時只會傳送暫存的測試資料，以估算當下的網路表現。

## 請注意

測速結果反映的是當下環境，可能受到 Wi‑Fi 訊號、裝置效能、其他正在使用網路的應用程式，以及測試端點距離影響。若想取得更具代表性的結果，建議在其他大量下載或串流活動暫停後重新測試。
